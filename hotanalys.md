
# Hotanalys - företag som använder e-post, microsoft 365, mobiltelefoner samt HR-system

# Hot
1. Intrång via HR-system, större risk via individer i företaget som har fler behörigheter
2. Stulen mobiltelefon kan leda till åtkomst på företagsinformation med inloggningsuppgifter
3. Anställda kan utsättas för phishing-attacker genom e-post

# Sårbarheter
1. Bristande utbildning/kunskap kring riskerna med e-post hantering där phishing-attacker förekommer
2. Samma & enkla lösenord på alla program/portaler, eller likadant på privat-/företagsmobil löper större risk
3. Oregelbundna och bristande uppdateringar av utrustning samt system och program 

# Skyddsåtgärder
1. Utbilda anställda kring säkerhet både i fysiska och digitala världen och löpande uppdatera dessa kunskaper
2. Multifaktorautentisering, så att tillfälligt skydd finns vid fall av stulna mobiltelefoner/enheter
3. Konfigurerar enheter, mobiler & datorer så att de automatiskt hämtar upp säkerhetsuppdateringar och inte lämnar hål som angripare kan utnyttja
