
# CIA-Analys

# Exempel: Phishing-attack genom e-post, hur det ser ut i CIA-triaden

# Konfidentialitet
Genom e-post kan angriparen lura användaren att klicka på fel länk och få dennes inloggninsuppgifter i värsta fall vilket ger angriparen åtkomst till företagsinformation och portaler bland annat. 
I detta fall äventyras verksamhetens sekretess.

# Integritet
Skulle angriparen få åtkomst till företagsinformation, mappar, filer så är risken stor att dessa ändras och då är innehållet inte längre korrekt dvs. manipulerat.

# Tillgänglighet
Om angripare lyckas spärra konton eller i värre fall infektera system så kan användare inte längre komma åt företagets filer och mappar. Användaren stängs ute från företagets system helt enkelt.
